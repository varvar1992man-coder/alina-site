# alina-site
Сайт нутрициолога Алины (демо для курса)

## Что на сайте

| Файл | Что это |
|---|---|
| `index.html` | главная страница: об Алине, услуги и цены |
| `calc/` | калькулятор калорий и БЖУ. Его можно установить на телефон как приложение, и он открывается внутри Telegram |
| `calc/config.js` | **настройки**: адрес бота для заявок и ник Алины в Telegram |
| `privacy.html` | политика обработки персональных данных (**заготовка — нужно заполнить**) |

Сайт работает на GitHub Pages: https://varvar1992man-coder.github.io/alina-site/

Все правки можно делать прямо на сайте GitHub: откройте файл → значок карандаша (**Edit this file**) → внесите изменения → **Commit changes**. Через 1–2 минуты сайт обновится.

## Заявки с калькулятора

После расчёта на странице калькулятора появляется форма **«Записаться на консультацию»**. В ней поля:

- имя;
- телефон или ник в Telegram;
- удобное время;
- галочка согласия на обработку персональных данных со ссылкой на политику. Галочка не стоит заранее: без неё заявку не отправить.

Заявка уходит на сервер Telegram-бота Алины. Бот сразу присылает её Алине в Telegram и добавляет строкой в Google Таблицу «Заявки». Как настроить бота и таблицу, по шагам описано в README репозитория бота: [alina-bot → «Заявки с сайта и Google Таблица»](https://github.com/varvar1992man-coder/alina-bot#заявки-с-сайта-и-google-таблица-заявки).

### Как подключить форму

1. Откройте на GitHub файл `calc/config.js` → карандаш.
2. Впишите адрес бота в кавычки после `LEAD_URL:`:

   ```js
   LEAD_URL: "https://АДРЕС_БОТА/lead",
   ```

   `АДРЕС_БОТА` — адрес вашего бота в Timeweb, тот же, что для уведомлений Продамуса. В конце обязательно `/lead`.
3. По желанию впишите ник Алины в Telegram (без `@`) в `TELEGRAM_USERNAME`. Если заявка не отправится, посетитель увидит ссылку «напишите Алине в Telegram».
4. **Commit changes.**

**Пока `LEAD_URL` пустой, форма на странице не показывается.** Так посетители не заполнят форму, которая никуда не уходит.

### Защита от спама

- **Скрытое поле-ловушка:** человек его не видит, а робот заполняет.
- **Проверка времени:** форму, отправленную быстрее чем через 3 секунды, сервер отбрасывает.
- **Лимиты на сервере бота:** число заявок с одного адреса и в час ограничено.
- **Только с этого сайта:** заявки принимаются только отсюда.

Подробнее — в README бота.

## Политика конфиденциальности

Файл `privacy.html` — **заготовка**. Перед тем как подключать форму:

1. Откройте `privacy.html` на GitHub → карандаш.
2. Найдите все места внутри `<span class="fill">…</span>`: на странице они выделены жёлтым. Впишите туда свои данные: ФИО или ИП, ИНН, e-mail для обращений, адрес сайта, ник в Instagram, какую нейросеть использует бот, срок хранения данных, дату.
3. Удалите жёлтый блок «Это заготовка политики…» в начале страницы (`<div class="draft">…</div>`).
4. **Проверьте текст с юристом.**

> ⚠️ **Честно:** я не юрист, и заготовка не заменяет консультацию.
>
> - Заявки сохраняются в Google Таблицах, а серверы Google находятся за пределами России. По закону о персональных данных (152-ФЗ) данные граждан РФ должны храниться в России, а о передаче за границу нужно уведомлять Роскомнадзор.
> - Возможно, Алине как оператору персональных данных нужно подать уведомление в Роскомнадзор.
>
> Уточните эти вопросы у юриста. Если Google Таблица не подходит, её можно отключить в настройках бота, и заявки будут приходить только в Telegram.

Ссылка на политику есть в форме заявки и в подвале главной страницы.

### Instagram и удаление данных (для проверки приложения Meta)

В политике есть два раздела специально для Instagram-бота:

- **Раздел 6 «Instagram: комментарии и сообщения»:** какие данные получает помощник, зачем, что передаётся нейросети, что хранится на сервере (только служебные отметки, 8 дней).
- **Раздел 9 «Как удалить свои данные»:** куда написать и что будет удалено.

При проверке приложения в Meta for Developers укажите эти адреса:

- **Privacy Policy URL** (политика конфиденциальности): `https://varvar1992man-coder.github.io/alina-site/privacy.html`
- **User data deletion** → **Data deletion instructions URL** (инструкция по удалению данных): `https://varvar1992man-coder.github.io/alina-site/privacy.html#delete`

*Названия полей в кабинете Meta — по памяти. Обычно они находятся в «Настройки приложения → Основное».* Если сайт переедет на свой домен, поменяйте адреса и там.

## Калькулятор внутри Telegram (Mini App)

Калькулятор открывается в боте кнопкой «🧮 Калькулятор калорий» или кнопкой меню «Калькулятор». Внутри Telegram он:

- **подстраивается под тему Telegram:** светлую, тёмную, цвета кнопок и фона. Тема меняется сразу, если её переключить в Telegram;
- разворачивается на весь экран и не показывает кнопки «Установить на телефон»;
- **сам подставляет в форму заявки имя и ник** из Telegram;
- отправляет вместе с заявкой подпись Telegram. Бот её проверяет, и Алина видит в заявке «Telegram (проверено)» со ссылкой на профиль.

В обычном браузере калькулятор выглядит как раньше, в цветах сайта. Скрипт Telegram загружается только внутри Telegram.

### В чём я не уверен

- Режим Telegram включается по служебным параметрам, которые Telegram добавляет к адресу страницы (`#tgWebAppData=…`). Я проверил это на имитации Telegram в браузере, а не в настоящем приложении Telegram. Откройте калькулятор из бота на телефоне и посмотрите, что тема подхватилась.

## Офлайн-режим

Установленный калькулятор работает без интернета. Раньше он показывал сохранённую версию даже при наличии интернета, поэтому правки на сайте могли долго не доходить. Теперь он сначала берёт свежую версию из интернета, а сохранённую использует, только если интернета нет. Изменения в `config.js` и на странице видны сразу.
